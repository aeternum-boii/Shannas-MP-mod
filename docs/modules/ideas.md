# Ideas

Prefix = aet_ideas

## Purpose 

Expanding the current idea groups by adding viable alternatives as well as rebalancing some of the existing idea groups with the main goal
of making them sharper and in general more engaging. A lot of the idea groups now employ systems that gate their buffs behind some other 
interaction you have to engage in.
