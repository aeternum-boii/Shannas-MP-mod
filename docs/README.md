# Mod Documentation

If you edit anything you should document it somewhere. The documentation is split into modules, you can also create a joint module for a lot of small edits named after yourself.
This is highly discouraged for anything actually interacting with other modules and not only with vanilla. An Example is in [exampleModule.md](modules/exampleModule.md).
